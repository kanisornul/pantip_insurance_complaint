# Pantip Insurance Complaint Analysis
NLP-based analysis and summarization of Thai insurance complaints from Pantip
This repository is intended primarily for educational and portfolio purposes.

## Project Overview
- This project analyzes insurance-related complaints and customer experiences shared on Pantip, one of Thailand's largest online discussion platforms.
- The project combines Natural Language Processing (NLP), text summarization, Large Language Models (LLMs), and Power BI to identify customer pain points and transform unstructured complaint text into actionable insights.
- The main objective is to compare different summarization approaches and develop a Hybrid Summarization Framework that combines extractive and abstractive methods.

## Objectives
- Analyze customer complaints related to the Thai insurance industry
- Identify major complaint topics and customer pain points
- Process and analyze large volumes of Thai-language text
- Compare extractive and abstractive summarization approaches
- Develop a Hybrid TextRank + LLM summarization approach
- Evaluate summarization quality
- Present business insights through an interactive Power BI dashboard
